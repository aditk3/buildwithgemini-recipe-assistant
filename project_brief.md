# Project Brief: Recipe Assistant

## Overview
A smart, interactive recipe and meal planning assistant built with Google ADK (Agent Development Kit). The assistant helps users discover recipes using available pantry ingredients, step-by-step cooking guidance, and recipe management capabilities.

## Objectives & Key Features
- **Pantry Search:** Suggest meals based on ingredients on hand, cooking time, and dietary restrictions.
- **Cooking Guidance:** Provide step-by-step instructions, prep times, and substitution tips.
- **Favorites Management:** Allow users to save and retrieve favorite recipes locally.
- **Shopping List:** Generate grocery lists for missing ingredients required for selected recipes.

## Tech Stack
- **Framework:** Google ADK (Python)
- **Model:** Gemini 2.5 Flash (`gemini-2.5-flash`)
- **Protocol:** ADK & A2A
